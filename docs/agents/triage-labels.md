# Triage labels

The labels this repository's issues use for where an issue stands, besides the kind labels (`bug`, `enhancement`, `documentation`, `accessibility`, `good first issue`).

| Label | Meaning |
|---|---|
| `needs-info` | Waiting on a decision or more information |
| `ready-for-agent` | Specified and ready to build |
| `waits-for-release` | Blocked until the release that can read it has shipped and its waiting period has passed |
| `wontfix` | Will not be worked on |

An issue with none of these has not been triaged yet.
