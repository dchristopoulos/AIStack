# Prototype: the page organised by project

Throwaway. One medium setup (two computers, four coding agents, three projects, twelve skills,
ten rule files) drawn three ways, switchable with `?variant=A|B|C` and the arrow keys:

- A: the computer tree as it was, filled in.
- B: organised by project, coding agents as columns, a + on each item. Chosen in ADR-0037.
- C: B with the open file beside the list.

Open `index.html` through any static server from this folder. The screenshots are B's dialogs:
add a project by its folder, a rule's side panel, sharing an edit, starting an agent.
